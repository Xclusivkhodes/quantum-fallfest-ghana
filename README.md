# Quantum projects for Qiskit Fall Fest 2026 (Ghana)

Four small, honest quantum computing projects built with Qiskit. Everything runs on simulators, and each one is a tiny teaching model, not a quantum speed-up.

| Project | Presenter | Folder | Live demo (open in Colab) |
|---|---|---|---|
| Drug-resistant typhoid: quantum chemistry warm-up (VQE on H2, with a noise study) | Benita Mensah | `typhoid-quantum/` | `notebooks/typhoid_h2_vqe_demo.ipynb` |
| Dumsor: fairer load-shedding schedules with QAOA (12 qubits) | Caleb Kwabla Adams | `ghana-quantum/dumsor/` | `notebooks/dumsor_qaoa_demo.ipynb` |
| Galamsey mercury: does mercury prefer sulfur over oxygen? (VQE, 8 qubits) | Oreson Malboba | `ghana-quantum/mercury/` | `notebooks/galamsey_mercury_vqe_demo.ipynb` |
| Error mitigation: SA-ZNE, symmetry-gauged zero-noise extrapolation | Gbewonyo Felix Elikplim | `quantum-concept/` | `notebooks/error_mitigation_demo.ipynb` |

## Run a demo
1. Open https://colab.research.google.com, choose File, then Upload notebook (or the GitHub tab), and pick a notebook from `notebooks/`.
2. Choose Runtime, then Run all. The first cell installs Qiskit, and each demo takes about 1 to 3 minutes.
